# 游戏设计草案（草稿，随时推翻）

## 一句话概述

用宝石造塔、合成宝石升级塔，守住一波波怪物的进攻。

## 核心循环

```
波次开始 → 怪物沿路线进攻 → 击杀掉落金币/宝石
   ↑                              ↓
下一波更强 ← 波间隙：建造/合成/升级宝石塔
```

## 宝石玩法创意（本项目差异点）

- 宝石既是"塔"也是"材料"：同色宝石可合成高一级宝石，攻击力质变。
- 属性方向：红=高伤、蓝=减速、绿=毒/持续、黄=连锁闪电、紫=暴击（待讨论）。
- 想法池：BOSS 掉稀有宝石 / 宝石可镶嵌到地形形成组合效果 / 每局随机宝石商店。
